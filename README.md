# 🧮 Simple Calculator Using Python

## 📌 Project Description
This is a simple calculator application developed using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

The project demonstrates fundamental Python programming concepts, including user input, conditional statements, functions, and basic error handling.

## 🚀 Features
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Accepts user input
- ✅ Displays calculation results
- ⚠️ Handles division by zero and invalid inputs

## 🛠️ Technologies Used
- **Programming Language:** Python 3
- **Concepts:** Functions, Conditional Statements, User Input, Arithmetic Operations
